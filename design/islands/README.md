## 文件与生成方式

使用内置 image_gen，未使用 CLI／API 回退。完整提示词和逐章约束在 `redesign-brief.json`；生成结果与设计稿对应关系在 `landmarks-v2/generation-manifest.json`。

- `landmarks-v2/source/chapter-NN.png`：当前完整透明 PNG 设计稿。
- `../../public/assets/islands/v2/chapter-NN.webp`：游戏运行素材，512 × 512，图片地址带 v2 路径以避免旧图缓存。
- `runtime-art-report.json`：本版文件尺寸、体积与 RGBA 解码估算。
- `source/` 与 `generation-manifest.json`：上一版小幅调整的原稿和提示词，保留供回退。
- `archive-v1/`：上一版总览与资源报告。
- `../../scripts/prepare-art.mjs`：等比缩小并转 WebP，不改动原画内容。
- `../../test-results/island-themes.png`：全部岛屿以游戏显示大小排列的检查总览。

## 内存与检查范围

每幅运行图保持 512 × 512；RGBA 像素约每岛 1 MiB、全部 22 MiB，不包含浏览器、渲染层、引擎或其他图片。地图继续按视口加载，屏幕外岛屿暂停浮动动画。视觉区分度增加不会增加运行图的像素尺寸。

资源自动检查只验证路径、加载、尺寸和动画暂停，不能用“22 条不同图片地址”证明“22 座视觉上足够不同”。总览需要按游戏尺寸人工比较主要轮廓、主建筑和颜色分布。
