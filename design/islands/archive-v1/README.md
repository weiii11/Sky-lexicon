上表是美术设计意图，游戏章节名称以词库为准。细微主题元素主要供探索时辨认，缩略图优先保证整体风格一致。

`generation-manifest.json` 保存每幅的完整提示词、基础参考、生成文件路径和设计稿路径。最初的基础岛屿与荷塘提示词见项目 `ART_PROMPTS.md`。

- `source/chapter-NN.png`：完整原始设计稿，22 幅全部保留。
- `../../public/assets/islands/chapter-NN.webp`：运行素材，512 × 512，对应页面约 215–235 CSS 像素。
- `runtime-art-report.json`：源图/运行图文件大小、像素尺寸、RGBA 解码内存估算。
- `../../scripts/prepare-art.mjs`：使用 sharp 生成运行素材，支持 `SHARP_MODULE` 指定已安装模块。

图片文件体积与浏览器内存不同。512 × 512 × 4 字节 = 每岛约 1 MiB；22 座全部解码约 22 MiB，不含浏览器、渲染层、引擎或其他图片。初次打开按视口加载，屏幕外浮动动画暂停；滚动浏览过的图片可能继续被浏览器缓存。
