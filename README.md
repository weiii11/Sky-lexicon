# 云间词屿 · Sky Lexicon

雅思词汇打字小游戏首版。一个主题章节对应一座岛屿，共 22 座；在岛屿中通过青蛙跳荷叶练习拼写，错词自动加入单词本。

## 直接试玩

首次从 GitHub 获取项目后，先按下方开发步骤安装依赖并构建。若本机已有 `dist/`，双击本目录的 `启动游戏.cmd`，保持终端窗口开启，在浏览器打开 <http://127.0.0.1:5173/>。

源码 HTML 入口为 `index.html`，构建后的网页入口为 `dist/index.html`，运行时需保留完整 `dist/assets/`。项目源码不包含依赖目录、构建产物或浏览器进度备份。

## 开发

环境：Node.js 22.7+、pnpm 11.25。依赖版本锁定于 `pnpm-lock.yaml`。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

没有包管理器时，也可以使用已安装依赖：

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1
node node_modules/typescript/bin/tsc --noEmit
node --experimental-transform-types --test tests/learning.test.ts
node node_modules/vite/bin/vite.js build
```

## 已实现规则

- 22 个主题分别对应 22 个独立岛屿，首版全部可选。桌面有主题目录与搜索，手机可在岛屿详情的选择框切换主题。
- 当章节内每个不同英文词条（包括短语）都至少答对一次，岛屿即「完整探索」：首次达到时弹出点亮纪念卡并播放约 4 秒的烟花；地图获得金色光晕、星形徽记和「已点亮」目录标记。状态由已有学习记录计算，刷新与导入后保留，重置后清除；已完成的岛不会每次答题都再放烟花。普通练习与复习均可推进探索，共享词可以同时点亮多个岛。
- 地图已移除会被岛屿标签遮挡的额外分区标题。
- 桌面从「已探索词汇 → 展开」查看至少答对一次的全部词汇；手机从顶部嫩叶图标进入。跨章节同词合并计数，支持搜索、主题筛选、每页 40 词、展开完整释义与音标。可复习单词、全部或筛选后的词；复习延续已有熟练度，不增加岛屿通关记录。
- 每轮 12 次正确跳跃、3 次落水机会。单词完整拼对自动判定，不区分大小写；允许退格修改，按 Enter 提交错误答案才判定拼错。
- 等待超时或脚下荷叶漂出边界会落水。三种错误都记录当前目标词。
- 英文与中文释义直接显示在目标荷叶表面，不使用卡片底框、额外提示行或提交箭头。未输入字母保持深色，已输入字母以浅蓝填色配细蓝描边加粗，错误字母用深红与浅底区分；中文回忆的横线和光标也加深。右侧详情默认收起，可从工具栏展开，选择随进度保存。
- 答对次数按英文词条累计；第 2 次答对后，下次仅给中文释义，英文字母用等长横线占位，随输入填回，退格后恢复横线。短语空格与标点保留。中文回忆时答错，下次恢复英文辅助，重新答对后回到中文回忆。既有的答对次数继续有效。
- 每轮结算展示实际出现过的全部词汇，包括答对与答错的词。重复词合并统计出现次数、答对和落水次数；点击词条可展开音标、中文释义、主题、累计答对次数及错误输入。
- 单词本可搜索、移出词条、进入复习。移出不删除学习历史。
- 慢／中／快三档节奏，可暂停；切换浏览器焦点会暂停，回到页面后手动继续。
- 学习记录存于本浏览器 `sky-lexicon:v1`。可从设置导出、导入 JSON 备份。导入会替换现有新版记录。
- 设置中的「重置学习进度」需要二次确认；清空学习历史、错词本和岛屿记录，回到第一座岛，保留声音、节奏、短语和注释偏好。已导出的备份可重新导入；重置后不会再次迁入旧原型错词。若无法写入浏览器存储，保留原进度并提示重试。
- 若与旧版同源，可一次性迁移旧 `lt_mistakes` 中能匹配的错词。旧版的掌握标记与分数无法还原答对次数或跳跃数，因此不映射为新版熟练度。旧存储键不清除。
- 默认练习单词；设置中可开启 9 个短语的练习。全部长词和原始词条都保留。

## 词库

来源：[LynnShaw/vocabulary_for_ielts](https://github.com/LynnShaw/vocabulary_for_ielts)。2026-10-14 下载的原始 CSV 保存在 `data/word_list.csv`。共 3,632 条、3,592 个不同英文文本、22 个章节；其中 9 个短语。下载时全部条目有中文释义，释义准确性没有逐条人工校对。

运行 `pnpm data` 或 `node scripts/import-vocabulary.mjs` 可从本地 CSV 重建 `src/vocabulary.json`。导入脚本保留章节、音标、释义、短语，记录原始文件 SHA-256；运行游戏不请求在线词库。

## 结构

- `src/catalog.ts`：章节、地图布局与岛屿素材映射。
- `src/progress.ts`：熟练度、错词本、保存与旧记录迁移。
- `src/session.ts`：出题、判定、倒计时、生命与结算，不依赖画面。
- `src/game.ts`：Phaser 游戏场景，统一使用 1000 × 720 的逻辑坐标。
- `src/exploration.ts`：整岛探索的去重计数与完成判定。
- `src/celebration.ts`：有时间与画布尺寸上限的烟花；停止、关闭或切走页面时清理，不在后台持续运行。减少动态效果偏好下只显示静态纪念卡。
- `src/main.ts`：地图、游戏 HUD、单词本和设置界面。
- `src/game-ui.ts`：荷叶文字、可选右侧注释与本轮词汇回顾。
- `src/typing.ts`：逐字反馈、中文回忆横线、空格与标点处理。
- `src/style.css`：响应式布局、配色与动画。
- `tests/learning.test.ts`：词库完整性与学习规则测试。
- `scripts/browser-check.mjs`：可选 Playwright 浏览器检查，支持 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE` 环境变量；截图写入 `test-results/`。
- `scripts/progress-ui-check.mjs`：已探索词汇分页／搜索／筛选／复习、手机布局、重置确认／取消／持久化与备份恢复检查，使用独立浏览器数据。
- `scripts/achievement-check.mjs`：文字对比度、整岛达成、烟花暂停与释放、连续游戏／结算衔接、共享词、手机与减少动态效果检查。
- `scripts/serve.mjs`：只读、仅绑定本机的生产预览服务器。

## 当前美术与后续迭代

22 座主题岛屿采用统一的透明手绘插画，以不同的主要地标、建筑和地形轮廓区分章节：山峰石拱、湿地鸟巢、晶石实验室、古迹石柱、露天剧场、帆船港口、钟楼等。02／04／05 保留古树、观星台、学院原画，其余 19 座按独立主题重新创作，避免只在相同建筑旁添加细小配件。完整提示词、设计稿与对应关系见 `design/islands/`；旧版本保留供比较和回退。关卡使用同画风的荷塘背景。

游戏已使用用户选定的 A 款「糯米团子蛙」。三款原始候选与生成提示词保存在 `design/frog-concepts/`。

原始 PNG 保存在 `design/`，网页只加载 512 × 512 的岛屿 WebP（每岛约 1 MiB RGBA 解码估算）。地图按视口延迟加载图片，屏幕外岛屿暂停浮动动画。`scripts/prepare-art.mjs` 可从设计稿重建素材，需可用的 `sharp`，也可用 `SHARP_MODULE` 指定模块位置。资源尺寸与体积见 `design/islands/runtime-art-report.json`，浏览器测量见 `test-results/memory-before.json` 和 `memory-after.json`。

后续可细化角色动画与关卡背景，并评估词条校对、中文释义歧义和更细的复习调度。当前 12 次跳跃的通关只表示完成一轮练习，不代表学完该章节。

网页字体有可选的在线增强；断网时使用系统字体。游戏逻辑、词库、引擎与图片均由本地构建提供。

完整验证范围见 `VALIDATION.md`，浏览器截图与机器报告位于 `test-results/`。
